# Regulatory Authority Logos

Drop the official logo files here using these exact filenames. They appear
automatically in the "Obtain Authorization from Government Regulatory
Authorities" banner (Why Legal Door section). Until a file is present, a clean
styled text seal is shown as a fallback, so nothing ever looks broken.

Use square PNGs with a transparent or white background (≈ 256×256px works well).

| Filename          | Authority                                   |
|-------------------|---------------------------------------------|
| `iso.png`         | ISO Certified                               |
| `fssai.png`       | FSSAI                                        |
| `msme.png`        | MSME / Udyam                                 |
| `ip.png`          | Intellectual Property India                 |
| `mca.png`         | Ministry of Corporate Affairs               |
| `gst.png`         | GST                                          |
| `incometax.png`   | Income Tax Department                        |
| `ugc.png`         | University Grants Commission                |
| `mci.png`         | Medical Council of India                     |
| `eci.png`         | Election Commission of India                 |

Note: some of these are Government of India emblems whose use is restricted by
law — only add logos your business is authorised to display.
